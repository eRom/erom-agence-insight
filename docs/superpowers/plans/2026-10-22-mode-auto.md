# erom-insight : mode auto, implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter aux trois skills d'erom-insight (`harness`, `tool-claude`, `skill-claude`) un mode auto, activé par le token `--auto`, qui va jusqu'au rapport sans jamais s'arrêter, sans `SendUserFile`, sans écriture mémoire, et termine par une ligne lisible par une machine.

**Architecture:** Aucun code nouveau dans le plugin : une section « Mode auto » en tête de chaque `SKILL.md`, et une déviation explicite à chacun de ses points d'arrêt, d'envoi et de mémoire. La preuve vient d'un script e2e hors plugin qui lance `claude -p` sur le plugin de travail (`--plugin-dir`) et inspecte le flux `stream-json`.

**Tech Stack:** Skills Markdown Claude Code ; script e2e Bun (TypeScript) ; `claude` 2.1.308 (`-p`, `--plugin-dir`, `--output-format stream-json --verbose`).

**Spec:** `/Users/recarnot/dev/erom-agence-backlog/docs/superpowers/specs/2026-10-22-backlog-triage-design.md`, section 12 « Chantier préalable : mode auto des deux plugins », et AC-5, AC-14. Contrat consommé par le backlog : `/Users/recarnot/dev/erom-agence-backlog/docs/superpowers/plans/2026-10-22-backlog-triage.md`, section « Interface consommée des plans plugins ».

## Global Constraints

- Contrat d'appel, fixé par le plan backlog : prompt `/erom-insight:<harness|tool-claude|skill-claude> <owner/repo|url|chemin> --auto`. Le token `--auto` peut être n'importe où après le premier token ; il est retiré du focus d'intention.
- En mode auto, la **dernière ligne non vide** du dernier message est exactement `[REPORT] <chemin absolu du rapport>` ou `[ABORT] <cause en une phrase>`. Rien après.
- Mode auto : aucun arrêt qui attend une réponse, aucun `AskUserQuestion`, aucun `SendUserFile`, aucune écriture en mémoire durable (mémoire built-in, mémoire d'agent, playbook, `_memory_/`).
- Sans `--auto`, le comportement de chaque skill est **strictement inchangé**.
- Rien de la cible n'est jamais exécuté, en mode auto comme ailleurs.
- Aucun tiret cadratin dans les fichiers écrits (hook `guard-emdash`). Vocabulaire : « reprendre », jamais « voler ».
- Gate de vérification du dépôt (`_memory_/patterns.md`) : `claude plugin validate plugin --strict` **et** le contrôle maison des frontmatters.
- Commits en français libre, une branche de travail pour le chantier, merge fast-forward dans `main` sur demande explicite de Romain.
- Le dépôt a un `.gitignore` modifié qui n'est pas à ce chantier : ne jamais le stager.

## Review Focus

1. **`--auto` placé avant la cible** (`/erom-insight:harness --auto owner/repo`). Attendu : reconnu, la cible reste le premier token restant. Test : Task 1, cas `auto-first`.
2. **Plugin publié résolu à la place du plugin de travail.** Le cache publié (0.6.0, désactivé) peut capter le namespace. Attendu : le e2e prouve que le `SKILL.md` chargé vient du dépôt. Test : Task 1, contrôle `base dir`.
3. **Scratchpad absent en `claude -p`.** Les trois skills clonent « dans le scratchpad de session ». Attendu : repli `mktemp -d`, nettoyage à la corbeille. Test : Task 5, cas remote.
4. **Arrêt de sécurité de `skill-claude` en mode auto.** Attendu : rapport minimal écrit puis `[REPORT]` (le rapport existe, verdict `stop-secu`), pas `[ABORT]`. Test : Task 4, fixture `skill-piegee`.
5. **Rapport du même jour déjà présent.** Attendu : suffixe `-2` comme aujourd'hui, et le chemin de la ligne `[REPORT]` est celui du nouveau fichier. Test : Task 5, deuxième passage du même cas.

**Interfaces:**
- Produces : `bun docs/evals/mode-auto/run-auto.ts <caseId>` ; écrit `docs/evals/mode-auto/out/<caseId>.jsonl` (flux brut) et affiche un JSON `{ caseId, lastLine, reportPath, reportExists, forbiddenTools: string[], memoryWrites: string[], skillBaseDir, pass, why }`.

Le script, pour un cas :
1. `touch` d'un marqueur dans le scratchpad du run.
2. Lance, prompt sur stdin, cwd `/Users/Shared/erom-agence-backlog-worker` : `claude -p --plugin-dir /Users/recarnot/dev/erom-agence-insight/plugin --model sonnet --effort high --permission-mode auto --permission-prompts none --output-format stream-json --verbose --no-session-persistence`.
3. Lit le flux : `lastLine` = dernière ligne non vide du `result` final ; `forbiddenTools` = noms de `tool_use` parmi `SendUserFile`, `AskUserQuestion` ; `skillBaseDir` = chemin extrait de « Base directory for this skill: » dans le contenu injecté.
4. `memoryWrites` = `find /Users/recarnot/.claude -path '*memory*' -type f -newer <marqueur>` **et** `find /Users/recarnot/dev/erom-agence-insight/_memory_ -newer <marqueur>`.
5. `pass` si : `lastLine` correspond à l'attendu du cas, `forbiddenTools` vide, `memoryWrites` vide (après retrait des fichiers d'autres sessions actives : les lister et les juger à la main, jamais les ignorer en silence), `skillBaseDir` commence par `/Users/recarnot/dev/erom-agence-insight/plugin/`.
