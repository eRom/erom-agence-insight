# Demo format

Cette skill reformate un texte fourni dans la conversation. Elle ne lit aucun fichier, n'execute aucune commande et n'appelle aucun service.

1. Lire le texte colle par l'utilisateur.
2. Rendre une liste a puces, une idee par puce, sans rien ajouter.
