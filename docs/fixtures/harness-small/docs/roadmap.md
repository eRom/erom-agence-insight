# Feuille de route

## Court terme

Brancher le budget de caracteres dans la boucle. Detecter la repetition d'un meme appel d'outil. Ajouter les tests listes dans `testing.md`.

## Moyen terme

Schema d'entree et description par outil. Liste d'autorisations par outil, voir `permissions.md`. Compaction de l'historique au-dela d'un seuil.

## Long terme

Brancher un vrai modele et mesurer le cout d'une tache type. Decider du sort de la memoire : fichier unique ou memoire par portee.

## Hors perimetre

Interface graphique, systeme de plugins, memoire partagee entre utilisateurs, execution distante.

## Criteres de succes

Un nouveau lecteur comprend le code en une heure. Une tache de vingt tours se termine sans depasser la fenetre du modele.
